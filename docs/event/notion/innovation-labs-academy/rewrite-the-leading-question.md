# Rewrite the Leading Question

**Instructions:**
Each question below would produce an answer you can't trust — leading, yes/no, or hinting at the solution. Rewrite it so a stranger could answer honestly in either direction. There's no single correct rewrite.

Check yours against three things: can it be answered yes/no, does it name your solution, does it ask about a feeling instead of a behavior.

**Worked example:**

- Leading: "Would you find it useful if there was an app that helped you track expenses?"
- Rewrite: "Walk me through how you kept track of your spending last month."
- Why: behavior-based, no yes/no exit, no hint at the solution.

**To rewrite:**

1. "Do you think a booking widget would save you time?"
1. "Wouldn't it be easier if invoices were automated?"
1. "Don't you think this feature would make your life easier?"
1. "Would you use a subscription box if it existed?"
